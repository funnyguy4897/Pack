# Pack Mixer (Fabric, Minecraft 1.21.11, client-only)

Press **K** in game, or **Mods > Pack Mixer > Configure** (Mod Menu). Click a card to apply it.
Left side: use **< >** to switch groups (PvP, Items, Blocks, World, HUD & GUI, Sounds). Right side **THEMES** tab: glass presets, opacity, corner roundness, UI size, blur.
Drop a resource-pack .zip on the window to import it; it is split into every collection it contains.

Collections come from `src/main/resources/packmixer/collections.json`, generated by `python3 tools/gen_collections.py` (edit and re-run to add or split more).
Build: push to GitHub (Actions builds the jar), or JDK 21 + Gradle 9.2+ and `gradle build`.
